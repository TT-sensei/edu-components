EDUCATIONAL JAVASCRIPT COMPONENTS

edu-components

小学校向けWeb教材で繰り返し使う仕組みを、Vanilla JavaScriptで。

操作できるカタログ

各デモは、部品を実際に動かして結果を確認できます。

画面管理

ScreenManager

教材のHOME・PLAY・RESULTなどを切り替える部品。

ホーム画面
問題に挑戦中
結果画面
簡単な使用例
const manager = new ScreenManager({ screens: document.querySelectorAll('.screen') });
manager.show('PLAY');
問題管理

QuestionPool

問題を絞り込み、重複を避けながらランダム・順番に出題する部品。

ボタンを押して出題

簡単な使用例
const pool = new QuestionPool(questions, { mode: 'random' });
const question = pool.next({ category: '算数', level: 1 });
正誤判定

AnswerChecker

文字列・数値・複数候補を判定し、正解・不正解イベントを発生させる部品。

正解例：Tokyo / 東京 / とうきょう

簡単な使用例
checker.check(userAnswer, ['東京', 'Tokyo'], { ignoreCase: true });
得点管理

ScoreManager

得点、正解数、不正解数、問題数、正答率をまとめて管理する部品。

簡単な使用例
score.correct(10);
score.wrong();
console.log(score.getResult());

      
連続正解
ComboManager
連続正解数と最大コンボを管理し、指定コンボ到達時に通知する部品。
0 COMBO
簡単な使用例
const combo = new ComboManager({ milestones: [3, 5] });
combo.correct();
eventTarget.addEventListener('edu:combo', handler);

      
問題形式
ChoiceQuestion / 4択
選択肢をシャッフルし、選択後の二重回答を防止します。

      
問題形式
TrueFalseQuestion / ○×
大きな選択領域で、タブレットでも押しやすい○×問題です。

      
問題形式
InputQuestion / 文字入力
Enterキーで回答でき、ソフトウェアキーボードを想定した入力欄です。

      
問題形式
NumberInput / 数字入力
教材内テンキーで0〜9、消す、全消去、決定を操作できます。
入力： 

      
問題形式
SortQuestion / 並べ替え
項目をタップして2つずつ入れ替えます。ドラッグ操作は不要です。

      
問題形式
MultiSelect / 複数選択
必要な個数まで選び、決定ボタンでまとめて判定します。

      
復習
RetryWrong / 間違い直し
間違えた問題を記録し、あとから「間違えた問題だけ」に取り組めます。
間違えた問題：0問

      
チャレンジ
60秒チャレンジ
スタートして、問題に答え、時間切れまでのスコア・コンボ・ランクを確認します。
60秒スコア 0コンボ 0
スタートを押してください。

      
保存
StorageManager
教材ごとのnamespaceで、数値・文字・boolean・配列・object・nullを安全に保存します。再読み込み後も値を確認できます。
namespace分離チェック：同じキーに別々の値を保存

      
学習進捗
ProgressManager
問題・単元・ステージなどの完了状況を管理します。StorageManagerと組み合わせると、再読み込み後も進捗が残ります。
0 / 50%
簡単な使用例
const progress = new ProgressManager({
  storage: new StorageManager('my-lesson'),
  ids: ['lesson-1', 'lesson-2']
});
progress.complete('lesson-1');

      
レベル管理
LevelManager
現在のレベルを最小値・最大値の範囲内で管理します。保存あり・保存なしの両方に対応します。
Lv1Lv1〜Lv5
簡単な使用例
const level = new LevelManager({ min: 1, max: 5 });
level.up();
level.setLevel(5);

      
解放管理
UnlockManager
レベル・ステージ・単元など、IDで表せる項目の利用可能状態を管理します。
小さな統合例：Lv1完了 → Lv2へ → Lv2解放
簡単な使用例
progress.complete('lesson-1');
level.setLevel(2);
unlock.unlock('level-2');

      
達成管理
AchievementManager
「はじめてクリア」「5コンボ」など、教材側で判定した達成項目を記録します。達成条件そのものや表示演出は担当しません。
簡単な使用例
achievement.achieve('first-clear');

      
バッジ管理
BadgeManager
教材側から渡したバッジ定義と、獲得済み状態だけを管理します。画像URLは自由に指定できます。
簡単な使用例
badge.award('clear-badge');

      
統合
正解 → Achievement → Badge
ScoreManagerの正解数を教材側で確認し、AchievementManagerとBadgeManagerをイベントで接続する小さな例です。
正解数：0　スコア：0
